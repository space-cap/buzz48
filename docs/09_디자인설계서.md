# 09. 디자인설계서 (Design Specification)

본 설계서는 **버즈48 (Buzz48)** 프로젝트의 프론트엔드 비주얼 스타일과 디자인 시스템을 규정합니다. 
본 시스템은 가독성이 높고 미려한 **소프트 라이트 모드(Soft Light Mode)**와 트렌디한 **슬릭 다크 모드(Sleek Dark Mode)**를 동시에 지원하는 듀얼 테마 시스템을 탑재하며, CSS 변수를 활용하여 원터치로 테마가 실시간 전환되도록 설계되었습니다.

---

## 1. 타이포그래피 (Typography)

* **제목 및 로고, 중요 메타 정보**: `Outfit` (기하학적이며 현대적 감각의 글로벌 산세리프 폰트)
* **본문 및 실시간 채팅 텍스트**: `Inter`, `-apple-system`, `BlinkMacSystemFont`, `Apple SD Gothic Neo`, `sans-serif` (가독성이 극대화되고 줄 간격 대비 눈이 편안한 글로벌 표준 시스템 폰트 혼용)

---

## 2. 컬러 시스템 & CSS 변수 스펙

모든 컴포넌트는 아래 정의된 CSS 변수만을 사용하여 비주얼을 렌더링하며, 테마 변경 시 변수의 내용물만 스위칭됩니다.

### 2.1 CSS 변수 선언

```css
/* ========================================================
   1. 소프트 라이트 모드 (Soft Light Mode) - 기본값
   ======================================================== */
:root {
  --bg-color: #f8fafc;            /* 연한 그레이 슬레이트 배경 */
  --panel-bg: rgba(255, 255, 255, 0.75); /* 반투명 화이트 글래스 */
  --border-color: rgba(15, 23, 42, 0.08); /* 옅은 그레이 테두리 */
  
  --primary: #4f46e5;             /* 인디고 블루 */
  --primary-hover: #6366f1;
  --accent: #f43f5e;              /* 로즈 레드 (생존 마감 타이머) */
  --green: #10b981;               /* 에메랄드 그린 (LIVE 상태) */
  
  --text-main: #0f172a;           /* 딥 네이비 블랙 (고대비 가독성 확보) */
  --text-muted: #475569;          /* 슬레이트 그레이 */
  --shadow: 0 10px 25px -5px rgba(15, 23, 42, 0.08), 
            0 8px 10px -6px rgba(15, 23, 42, 0.05); /* 부드럽고 입체적인 그림자 */
  
  --chat-other-bg: rgba(15, 23, 42, 0.05); /* 상대방 채팅 말풍선 배경 */
  --chat-me-bg: #4f46e5;          /* 내 채팅 말풍선 배경 */
  --chat-me-text: #ffffff;
}

/* ========================================================
   2. 슬릭 다크 모드 (Sleek Dark Mode)
   ======================================================== */
[data-theme="dark"] {
  --bg-color: #090d16;            /* 심연의 네이비 블랙 */
  --panel-bg: rgba(17, 24, 39, 0.65); /* 반투명 다크 그레이 글래스 */
  --border-color: rgba(255, 255, 255, 0.08); /* 미세한 야광 테두리 */
  
  --primary: #6366f1;             /* 한층 밝아진 야광 인디고 블루 */
  --primary-hover: #818cf8;
  --accent: #fb7185;              /* 라이트 로즈 핑크 */
  --green: #34d399;               /* 라이트 에메랄드 */
  
  --text-main: #f3f4f6;           /* 소프트 화이트 */
  --text-muted: #9ca3af;          /* 쿨 그레이 */
  --shadow: 0 20px 25px -5px rgba(0, 0, 0, 0.5), 
            0 10px 10px -5px rgba(0, 0, 0, 0.4); /* 딥한 다크 섀도우 */
  
  --chat-other-bg: rgba(255, 255, 255, 0.08);
  --chat-me-bg: #6366f1;
  --chat-me-text: #ffffff;
}
```

## 3. 핵심 페이지 레이아웃 스펙 (UX/UI)

### 3.1 메인 대시보드 (`/`)
* **실시간 HOT 3 보드 (상단)**:
  * 10초 주기로 랭킹을 갱신하는 3개의 하이라이트 인기 카드 배치.
  * 라이트 모드에서는 소프트 인디고 광택 섀도우, 다크 모드에서는 오로라 네온 섀도우가 은은하게 맥박치듯 작동.
* **실시간 게시판 피드 (하단)**:
  * 무한 스크롤 형식의 피드 리스트.
  * 각 게시글 카드의 우측에 생존 시간 카운트다운 타이머(`18:42:19` 등)가 실시간으로 감소.
  * 수명 타이머는 마감 1시간 이내 진입 시 강렬한 악센트 컬러(`--accent`)로 자동 전환되어 긴박함을 연출.

### 3.2 상세 페이지 (`/posts/[id]`) [좌우 40:60 분할 구조]
* **좌측 패널 (40%) - 게시물 내용**:
  * 라이트 모드에서는 뽀얗고 투명한 글래스, 다크 모드에서는 사이버 그레이 글래스로 분할.
  * 좌측 최상단의 `[<]` 토글 버튼 클릭 시, 0.3초의 부드러운 슬라이딩 아웃 애니메이션과 함께 패널이 들어가며 우측 채팅창이 100% 가득 차는 전면 집중 채팅 뷰 제공.
* **우측 패널 (60%) - 실시간 채팅**:
  * **상단 메타 바**: 실시간 접속자 수 `🟢 LIVE | 👀 43명`을 선명하게 노출.
  * **채팅 타임라인**: 메시지가 아래에 쌓일 때 부드러운 페이드인과 위로 솟구치는 슬라이드 트랜지션 적용.
  * **반응 이모지 단**: 말풍선 우측 하단에 위치하며, 마우스 오버 시 입체적으로 커지고(Scale up) 클릭 시 버블 팝 효과 연출.
  * **입력 영역 가드 (이중 검증)**: 수명이 끝나 `READ`로 전환될 때, 자바스크립트에 의해 채팅 입력창이 아래로 사라지고 **"🔒 24시간이 경과하여 읽기 전용으로 전환되었습니다."** 문구가 나타남.

## 4. 모바일 반응형 대응 (Mobile Responsive)

* 화면 폭이 768px 이하로 좁아지면, 40:60 분할이 아닌 **1단 배치**로 변경됩니다.
* 상단에 **`[원글 보기]`** 및 **`[실시간 대화 💬 (동접자수)]`** 탭을 두어, 모바일 한정으로 스와이프나 클릭 스위칭을 통해 쾌적하게 뷰를 제공합니다.
