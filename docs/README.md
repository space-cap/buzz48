# 버즈48 (Buzz48) — 문서 개요

> **48시간 타임어택 실시간 토론 플랫폼**
> 게시글이 곧 채팅방이 되는, 48시간 동안만 살아있는 실시간 토론 서비스

---

## 프로젝트 한 줄 정의

> "지금 참여하지 않으면 놓친다" — 48시간 후 사라지는 토론방에서 실시간으로 이슈를 논하는 플랫폼

---

## 확정 기술 스택

| 영역 | 기술 |
| :--- | :--- |
| Frontend | Next.js (TypeScript) |
| REST API 서버 | Go + Fiber |
| WebSocket 서버 | Go + Gorilla WebSocket |
| 배치 워커 | Go |
| 인메모리 캐시 | Redis Cluster |
| 데이터베이스 | PostgreSQL |
| 인프라 | AWS ECS/Fargate + CloudFront |

## 핵심 비즈니스 규칙 요약

| 규칙 | 내용 |
| :--- | :--- |
| **LIVE 구간** | 생성 후 0~24시간. WebSocket 실시간 채팅 가능 |
| **READ 구간** | 생성 후 24~48시간. 읽기 전용 전환, PostgreSQL 서빙 |
| **DELETE** | 생성 후 48시간 이후. 플랫폼에서 영구 삭제 |
| **HOT 산출** | `(동접자 × 0.5) + (5분 채팅 수 × 0.3) + (5분 반응 수 × 0.2)`, 10초 갱신 |
| **이중 검증** | 방 상태는 캐시 무관하게 `created_at + 24h` 기준으로 매 요청마다 재계산 |
| **익명 세션** | 회원가입 없이 UUID 세션 + 자동 닉네임 부여 |
