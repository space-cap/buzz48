## 1. 금칙어 1차 필터 시스템
욕설, 광고, 음란물 등 유해성 게시물을 방지하기 위해 실시간 인메모리 금칙어 필터를 백엔드 단에 내장합니다.

* **기술 설계:**
  - **Trie (트라이) 알고리즘**을 활용한 인메모리 문자열 탐색 트리 구축 (Go로 구현).
  - 서버 시작 시 DB에서 금칙어 목록을 로드하여 Trie 메모리에 구성.
  - 게시물 작성 및 실시간 채팅 전송 시 미들웨어 또는 서비스 레이어에서 필터 작동.
* **사용자 경험 (UX):**
  - 금칙어 감지 시 메시지 전송을 차단하고 브라우저 화면에 알림 경고 출력.

## 2. 신고 API & 자동 블라인드
익명 플랫폼의 특성상 유해성 콘텐츠 유포를 막기 위한 유저 자정 작용 시스템을 구축합니다.

* **백엔드 설계:**
  - `POST /v1/reports` API 구현 (대상: 게시글 또는 특정 메시지).
  - 중복 신고 방지를 위해 **`session_id` 기준 동일 대상 1회 신고** 제약 설정.
  - 신고 데이터가 접수될 때마다 누적 카운트를 집계하여 **5건 이상 누적 시 즉각 블라인드** 처리.
* **프론트엔드 설계:**
  - 블라인드 처리된 게시글이나 메시지는 화면에서 즉각 가려지고 `"신고 누적으로 블라인드 처리된 메시지입니다"` 문구 노출.
* **백엔드 배치 워커 연동:**
  - 48시간 만료 배치 워커 가동 시 진행 중인 신고 대상 글은 완전 삭제를 보류하고, 법적 보존을 위해 `legal_hold_archive` 아카이브 테이블로 안전하게 분리 보존.

## 3. OAuth 2.0 소셜 로그인
기존 익명 UUID 세션 유저가 작성 글 목록을 추적하고 모바일 기기 변경 시 세션을 동기화할 수 있도록 간편 소셜 로그인을 제공합니다.

* **연동 대상:** 카카오(Kakao), 구글(Google), 네이버(Naver)
* **연동 구조:**
  - 프론트엔드에서 간편 로그인 요청 ➔ 백엔드에서 OAuth2 Core SDK를 통한 소셜 토큰 검증 및 유저 프로필 수신.
  - **UUID 익명 세션 바인딩**: 소셜 로그인 시, 기존 기기에 발급되어 있던 익명 세션의 내역(작성 글, 작성 채팅)을 소셜 계정과 1:1로 매핑하여 데이터 보존성 확보.

## 4. FCM 기반 실시간 푸시 알림
실시간 참여율과 유입률을 극대화하기 위해 웹/앱 브라우저 푸시 알림 시스템을 도입합니다.

* **알림 발송 시나리오:**
  1. **HOT 진입 알림**: 본인이 작성한 글이 실시간 인기(HOT) 랭킹에 진입했을 때 발송.
  2. **만료 임박 알림**: 본인이 개설한 글의 삭제(48시간 만료) 1시간 전에 경보 알림.
  3. **답장 및 리액션 알림**: 내 메시지에 답글이 달리거나 이모지 반응이 수집되었을 때 실시간 알림.
* **구현 아키텍처:**
  - Firebase Cloud Messaging (FCM) 연동.
  - 백엔드에 FCM 푸시 전송 비동기 큐 모듈 개발.
  - 프론트엔드 Service Worker를 통한 브라우저 백그라운드 푸시 수신 구현.

## 5. AWS S3 & CloudFront 이미지 업로드
직접 파일 서버 업로드 방식 대신 퍼블릭 오브젝트 스토리지와 글로벌 CDN을 활용해 인프라 부하를 경감합니다.

* **업로드 아키텍처 (Pre-signed URL):**
  1. 프론트엔드가 백엔드에 업로드용 임시 서명 URL 요청 (`GET /v1/uploads/presigned-url`).
  2. 백엔드는 AWS S3 SDK를 사용해 보안 유효기간(예: 5분)이 적용된 Pre-signed URL 생성 및 반환.
  3. 프론트엔드는 수신한 URL을 통해 **서버를 거치지 않고 AWS S3 버킷으로 직접 파일 업로드** 수행.
* **고속 전송 인프라:**
  - S3 전면에 **AWS CloudFront CDN**을 맵핑하여 이미지 조회 시 물리적 위치가 먼 유저에게도 지연시간 없이 캐싱된 이미지를 고속 전송.

## 6. 관심 게시글 북마크
48시간 이내에 폭파되는 게시물 중 자신이 마음에 들었던 게시물을 북마크하여 별도로 관리하는 공간을 만듭니다.

* **백엔드 설계:**
  - `POST /v1/posts/{post_id}/bookmark` (북마크 토글 API).
  - `GET /v1/users/me/bookmarks` (자신이 북마크한 글 조회).
* **프론트엔드 UI/UX:**
  - 메인보드 및 상세 패널 상단에 '북마크 리스트' 서랍장을 디자인하여 유저가 즐겨찾는 방으로 원클릭 진입 지원.

## 7. 인프라 모니터링 & 어뷰징 방어
프로덕션 운영 시 발생할 수 있는 대규모 커넥션 병목 현상 및 도스(DoS) 공격을 사전에 탐지하고 방어합니다.

* **어뷰징 및 다중 커넥션 방어:**
  - 동일한 IP/세션에서 짧은 주기로 웹소켓을 중복 생성하여 대량 커넥션을 점유하는 현상을 Redis 기반 Rate Limiting으로 방어.
  - 웹소켓 재연결(백오프) 시 60초 유예 정책을 정밀 튜닝하여 비정상 이탈/재연결로 인한 서버 오버헤드 최소화.
* **인프라 모니터링 대시보드 구축:**
  - AWS CloudWatch 혹은 Prometheus + Grafana를 사용하여 실시간 CPU, 메모리 사용량 및 Redis Active Connection 수 시각화.
  - 임계치 초과 시 슬랙(Slack) 혹은 디스코드(Discord)로 연동되는 알림 경보 봇 구축.
