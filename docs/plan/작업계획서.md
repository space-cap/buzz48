## Phase 1 — MVP 핵심 기능 구현

> **목표**: 토론방 생성 → 실시간 채팅 → 48시간 수명 주기가 동작하는 웹 서비스를 완성한다.
> **기간 목표**: 약 6~8주

### 1-1. 데이터베이스 & Redis 기반 작업

- [ ] PostgreSQL 테이블 생성 (`05_DB설계서.md` 기반)
  - [ ] `sessions` 테이블
  - [ ] `rooms` 테이블
  - [ ] `messages` 테이블
  - [ ] `reactions` 테이블
  - [ ] `reports` 테이블
- [ ] Redis 자료구조 설계 구현
  - [ ] `room:{id}:conn_count` (Hash — 동접자 수)
  - [ ] `room:{id}:stream` (Stream — LIVE 메시지 큐)
  - [ ] `hot:ranking` (Sorted Set — HOT 스코어)

### 1-2. REST API 서버 (Go + Fiber)

- [ ] **세션 API**
  - [ ] `POST /sessions` — 익명 세션 발급 + 랜덤 닉네임 생성
  - [ ] `PATCH /sessions/me/nickname` — 닉네임 변경

- [ ] **토론방 API**
  - [ ] `POST /rooms` — 방 생성 (idempotency_key 처리 포함)
  - [ ] `GET /rooms` — 타임라인 목록 (커서 페이지네이션)
  - [ ] `GET /rooms/hot` — HOT 상위 3개 조회
  - [ ] `GET /rooms/{room_id}` — 방 상세 조회
  - [ ] 방 상태 이중 검증 미들웨어 (`created_at + 24h` 재계산)

- [ ] **메시지 API (READ 전용)**
  - [ ] `GET /rooms/{room_id}/messages` — 과거 메시지 조회

- [ ] **Rate Limit 미들웨어**
  - [ ] 토론방 생성: 세션당 1시간 3개 제한 (Redis 기반)
  - [ ] 메시지 전송: 초당 5건 제한

### 1-3. WebSocket 서버 (Go + Gorilla)

- [ ] WebSocket 연결 핸들러
  - [ ] 연결 시 세션 토큰 검증
  - [ ] 연결 성공 시 `room_snapshot` 이벤트 전송 (최근 메시지 50개)
  - [ ] Redis `conn_count` INCR/DECR 처리
- [ ] 이벤트 처리
  - [ ] `send_message` — 메시지 수신, LIVE 검증, Redis Stream 저장, 브로드캐스트
  - [ ] `send_reaction` — 반응 처리 및 `reaction_updated` 브로드캐스트
  - [ ] `sync` — 재연결 시 누락 메시지 복구
- [ ] Redis Pub/Sub 기반 멀티 인스턴스 팬아웃
  - [ ] 메시지 발행 (`room:{room_id}` 채널)
  - [ ] 구독 및 브로드캐스트
- [ ] 서버 → 클라이언트 이벤트
  - [ ] `message_received`
  - [ ] `reaction_updated`
  - [ ] `conn_count_updated`
  - [ ] `room_state_changed`
  - [ ] `sync_result`
  - [ ] `error`

### 1-4. 배치 워커 (Go)

- [ ] **Lifecycle Worker** (1분 주기)
  - [ ] LIVE → READ 상태 전환 (24시간 경과 방 감지)
  - [ ] Redis 큐 → PostgreSQL Write-Behind 완료 확인 후 정리
  - [ ] `room_state_changed` 이벤트 발행

- [ ] **Purge Worker** (10분 주기)
  - [ ] READ → DELETE 처리 (48시간 경과 방 감지)
  - [ ] 관련 메시지·반응·이미지 일괄 삭제 (배치 500개 단위)
  - [ ] 진행 중 신고 건 아카이브 이관

- [ ] **HOT Score Worker** (10초 주기)
  - [ ] 전체 LIVE 방 스코어 계산
  - [ ] `hot:ranking` Sorted Set 업데이트

### 1-5. 프론트엔드 (Next.js)

- [ ] **메인 페이지** (`/`)
  - [ ] HOT 토론방 카드 3개 (실시간 갱신)
  - [ ] 카테고리 탭 필터
  - [ ] 타임라인 리스트 (무한 스크롤, 커서 페이지네이션)
  - [ ] `🟢 LIVE / 🟡 READ` 상태 배지 + 카운트다운 타이머

- [ ] **토론방 페이지** (`/rooms/[id]`)
  - [ ] 원문 게시글 영역 (접이식)
  - [ ] 실시간 채팅 UI (WebSocket 연결)
  - [ ] 메시지 입력창 (LIVE 상태일 때만 활성화)
  - [ ] 이모지 반응 버튼
  - [ ] 답장(Reply) 기능
  - [ ] READ 상태 전환 시 입력창 자동 잠금

- [ ] **토론방 생성 모달**
  - [ ] 제목·내용·카테고리 입력
  - [ ] Rate Limit 초과 시 안내

- [ ] **닉네임 설정 팝업**
  - [ ] 자동 부여된 닉네임 표시
  - [ ] 커스텀 닉네임 변경

- [ ] **OG 태그 동적 생성** (SSR)
  - [ ] `"이 토론방은 N시간 후 사라집니다"` 메타 태그

- [ ] **WebSocket 클라이언트 훅** (`useWebSocket`)
  - [ ] 자동 재연결 로직
  - [ ] `sync` 요청 처리

### 1-6. MVP 완료 검증

- [ ] 토론방 생성 → 실시간 채팅 E2E 동작 확인
- [ ] 24시간 후 READ 전환, 48시간 후 DELETE 동작 확인
- [ ] HOT 랭킹 10초 갱신 확인
- [ ] 멀티 브라우저(탭) 동시 접속 메시지 동기화 확인
