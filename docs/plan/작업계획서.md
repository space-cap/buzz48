## Phase 1 — MVP 핵심 기능 구현

> **목표**: 게시물 작성 → 실시간 채팅 → 48시간 수명 주기가 동작하는 웹 서비스를 완성한다.
> **기간 목표**: 약 6~8주

### 1-1. 데이터베이스 & Redis 기반 작업

- [x] PostgreSQL 테이블 생성 (`05_DB설계서.md` 기반)
  - [x] `sessions` 테이블
  - [x] `posts` 테이블 (기존 `rooms` → 이름 변경)
  - [x] `messages_archive` 테이블 (파티셔닝)
  - [x] `reactions_archive` 테이블
  - [x] `reports` 테이블
  - [x] `notifications_log`, `premium_posts`, `payments`, `settlements` 테이블
- [x] Redis 자료구조 설계 구현 (`internal/redis/keys.go`, `internal/redis/store.go`)
  - [x] `post:{id}:conn_count` (String — 동접자 수, INCR/DECR + 60초 유예)
  - [x] `post:{id}:messages` (Stream — LIVE 메시지 큐, XADD/XRANGE)
  - [x] `post:{id}:msg_times` (Sorted Set — 5분 슬라이딩 채팅 수)
  - [x] `post:{id}:reaction_times` (Sorted Set — 5분 슬라이딩 반응 수)
  - [x] `post:{id}:state_cache` (String — 상태 캐시)
  - [x] `hot:ranking` (Sorted Set — HOT 스코어 ZADD/ZREVRANGE)
  - [x] `session:{id}` (Hash — 세션 캐시)
  - [x] `rate_limit:post_creation:{session_id}` (String — Rate Limit 60분 윈도우)
  - [x] `disconnect_pending:{session_id}:{post_id}` (String TTL 60초 — 재연결 유예)
  - [x] `pubsub:post:{post_id}` (Pub/Sub — 멀티 인스턴스 팬아웃)
